# Product

## Register

product

## Users

Two roles. Regular users: send and receive notifications, manage their own inbox. Admins: same as users, plus can broadcast system notifications that reach every user. Both roles access the same shell — admins just have broader reach. Context of use: browser, work hours, intermittent attention.

## Product Purpose

Flow is a lightweight notification system for teams. Users send targeted messages to each other; admins push broadcasts that land for everyone. Success: a user opens Flow, sees what matters, acts, and leaves. No overwhelm, no friction.

## Brand Personality

Energetic, clean, direct. The orange (#FF6D1F) is the personality — it signals activity and urgency without shouting. The rest of the UI steps back to let content and the brand accent do the work. Not corporate-heavy, not startup-generic. A tool that feels built for people, not for enterprise procurement slides.

## Anti-references

- Jira, enterprise ITSM tools: dense menus, overloaded sidebars, everything is equally important so nothing is.
- Generic 2023–2024 SaaS cream/blue: the pale warm backgrounds, blue CTAs, icon-card grids with marketing copy.
- Aggressive neon energy: the orange should feel purposeful, not like a gaming dashboard.

## Design Principles

1. **One clear action per surface.** Every screen has a primary CTA. Navigation never competes with content.
2. **Brand energy through accent, not noise.** #FF6D1F on interactive elements, states, and focal points. Black, white, and grays carry the rest.
3. **Breathing room over density.** Generous padding prevents the corporate-heavy feel. Notifications need air to be readable at a glance.
4. **Role-aware, not role-obtrusive.** Admin capabilities surface contextually, not as a constant visual layer on top of the user experience.
5. **Instant legibility.** Notification titles, types, and read/unread states must be parseable in under a second.

## Accessibility & Inclusion

WCAG AA minimum. All interactive elements keyboard-navigable. Color is never the sole indicator of state (read/unread uses both color and weight). Dark mode supported by default.
